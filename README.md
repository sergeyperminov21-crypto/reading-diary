# 📖 Дневник чтения

Личный дневник для учёта прочитанной литературы. Работает полностью в браузере: без сервера, без регистрации, без сбора данных. Все записи хранятся локально в `localStorage`.

![preview](https://img.shields.io/badge/status-ready-brightgreen)

## Возможности

- 📚 Запись о книге: название, автор, жанр, объём, статус, оценка (1–5 ★), дата, отзыв, цитата
- 🔍 Поиск по названию, автору, отзыву, цитате
- 🏷️ Фильтр по статусу: «Хочу», «Читаю», «Прочитано»
- ↕️ Сортировка: новые, по названию, автору, оценке, объёму
- 📊 Статистика: всего книг, прочитано, страниц, средняя оценка
- 💾 Экспорт и импорт резервной копии в JSON
- 🌙 Адаптивная вёрстка и аккуратный «книжный» дизайн

## Запуск

### Локально
1. Скачайте или склонируйте репозиторий.
2. Откройте `index.html` в браузере — можно двойным кликом.

### Через локальный сервер (опционально)
```bash
python3 -m http.server 8000
# откройте http://localhost:8000
```

### Онлайн
Разверните репозиторий на **GitHub Pages**, **Netlify**, **Cloudflare Pages** или **Vercel** — это статический сайт, никакой сборки не нужно.

## Данные и приватность

- Всё хранится в `localStorage` браузера под ключом `reading-diary-v1`.
- Записи **не отправляются на сервер**.
- Чтобы перенести данные на другое устройство — используйте кнопки **⤓ (экспорт)** и **⤒ (импорт)**.
- Очистка данных сайта/браузера удалит записи — делайте бэкапы.
